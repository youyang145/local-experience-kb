# 演示（骨架端到端）

不是截图拼的，是一条脚本跑出来的：`dsh-kb/scripts/demo-e2e.mjs`，在临时目录建库，全程调用真实函数。

## 跑出来是什么样

```
[1] 存一条知识（工具/GG修改器）
    k261101brz0sb  工具/GG修改器  GG 搜不到数值时先换类型

[2] 把一段资料塞进来：自动分块 + 猜分区，只写「待分区」
    分 3 块，入库 3 块：k261101az1mt7, k261101737gn9, k261101d1op9i
    待分区条数：3

[3] 查库：先判要不要查，再给索引摘要与命中
    判定：查库（有信息需求）
    命中：GG 搜不到数值时先换类型

[4] 记一条经验，套用成功两次
    used=2  succeeded=2  优先级=10

[5] 人推翻它：保留为反例，不删除
    状态：refuted；检索默认不再推荐它

[6] 套用一条相似经验前，反例警示出现
    警示 1 条：搜不到数值时，先换数值类型再重搜。

[7] 收尾：统计
    {"blocks":6,"knowledge":4,"experience":2,"refuted":1}
```

## 这七步对应骨架的什么

| 步 | 骨架里的东西 |
|---|---|
| 1 | 分区两级路径 `工具/GG修改器` |
| 2 | `待分区` 收件箱 + ingest 分块/猜分区 |
| 3 | 查库判定 + 索引摘要 + 三元检索 |
| 4 | 复用记账（used / succeeded / 优先级） |
| 5 | 推翻保留为反例（不物理删除） |
| 6 | 反例警示只在"准备套用"时亮 |
| 7 | 统计与索引一致性 |

## 复现

```bash
cd dsh-kb
node scripts/demo-e2e.mjs
```

只需要 Node 22+，不装数据库、不联网。

## 界面入口

面板可以独立开（`启动面板.cmd`），也可以作为挂件嵌进 DSH 页面：右下角一枚可拖动的圆钮，点开是小弹窗，里面就是面板。挂件随插件安装，路径 `/dsh-kb/widget.js`。
