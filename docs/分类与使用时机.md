# 分类与使用时机

两件事写在这里：**东西放哪**、**什么时候去查**。

## 一、分区（放哪）

分区是两级路径：`分区/主题`。

```
blocks/
  工具/
    GG修改器/
    pnpm/
  数学/
    函数/
  示例/
    种子/
  待分区/          ← 收件箱：AI 拿不准的先放这，人再决定
```

规则：

1. **两级就够**，不搞任意深度；
2. **`待分区` 是收件箱，不是垃圾桶**：新东西默认进这里，人看过再挪；
3. **新建分区要人批**：AI 可以提议"要不要建「工具/GG修改器」"，不能自己建；
4. 选父分区时按前缀命中（选「工具」能看到「工具/GG修改器」里的东西）；
5. 领域路径不许出现 `..` 或空段，防止写出 blocks 根目录。

## 二、使用时机（什么时候查）

### 常驻模式关（默认）

- 不自动查；只有 `/调用 xx`，或你明确问"库里有吗"才查。

### 常驻模式开

| 场景 | 行为 |
|---|---|
| 闲聊、寒暄、纯计算 | 跳过，不读索引 |
| 技术问题、知识问题、要动手的活 | 读索引摘要（分区 + 每区前几条简介） |
| 索引命中 | 读命中条目的简介 |
| 简介相关 | 读正文（一次最多 3 条） |
| 命中 0 条 | 正常回答；可记一条"库里缺这个"到待分区 |
| 用户说"别查库/凭经验答" | 本轮跳过，不自动查 |
| `/调用 xx` | 强制读，跳过以上所有判定 |

### 经验块与反例

- 只主动推荐 `success` 且 `succeeded ≥ 2`、未 refuted 的经验；
- 其余经验只能被搜到，不主动进上下文；
- 反例不在每次搜索弹，只在**准备套用**或**高度相似**时提示。

## 三、把资料塞进来（ingest）

```
kb ingest 资料.md --title "资料名"     # 只出计划，不动库
kb ingest --apply 计划.json            # 确认后入库
```

1. **分块**：有标题按标题切，没标题按段落并，单块上限 ~1200 字；
2. **猜分区**：拿块里的词撞各分区已有内容，给前 3 个候选与分数；
3. **计划文件**：写到 `_ingest/plan-*.json`，每块带 `suggestions` 和空的 `chosen`；
4. **入库**：分区优先级 `chosen` > `--domain` > 候选最高分（≥0.15）> **待分区**；
5. AI 那一半以后接插件：读计划、填 `chosen`、再 apply；人不点头就不落盘。

## 四、查库命令（consult）

```
kb consult "GG 搜不到数值怎么办" --limit 3
```

输出：判定（查库/闲聊跳过）→ 索引摘要（分区 + 标题）→ 命中列表（简介）→ 反例警示。

- 整句查不到时会拆词兜底（二元组 + 拉丁词逐个 LIKE）；
- 只回简介，不读正文；要不要读正文、读几条，由调用方决定（默认最多 3 条）。

## 五、验收

- 分区：新建一条不填领域 → 落 `待分区`；选「工具」能查到 `工具/GG修改器` 下的块；
- 使用时机：常驻开时问技术问题，能看到索引摘要；问"你好"不触发检索。
